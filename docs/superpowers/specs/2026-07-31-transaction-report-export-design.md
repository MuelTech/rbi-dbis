# Transaction Report Export Design

## Overview

Update CSV and PDF export to fetch ALL filtered transactions (not just current page) for complete data export.

## Behavior

When user clicks CSV or PDF:
1. Fetch ALL transactions matching current filters (period + personnel) — ignoring pagination
2. Export the complete dataset to file
3. PDF automatically paginates if table exceeds one page
4. Search filter is active in the data but not shown in the report header

## Backend

### New Endpoint

`GET /api/dashboard/transactions/export`

Query params:
- `period` (string): day | week | month | custom
- `from` (string): start date for custom period
- `to` (string): end date for custom period
- `personnelId` (string): filter by specific user

Response:
```json
{
  "data": Transaction[],
  "summary": { "accumulatedFee": number, "totalTransactions": number }
}
```

No pagination — returns all matching records.

## Frontend

### Dashboard Service

Add `getTransactionsExport()` function:
```typescript
getTransactionsExport: (params: {
  period?: string;
  from?: string;
  to?: string;
  personnelId?: string;
}) => Promise<{ data: Transaction[]; summary: {...} }>
```

### TransactionSection

Update `handleExportCSV` and `handleExportPDF`:
1. Call `getTransactionsExport()` with current filters
2. Generate file from complete dataset
3. Show loading state while fetching (optional)

## CSV Export

- Columns: OR Number | Date Issued | Personnel | Resident | Type | Fee
- Totals row at bottom: TOTAL | [count] transactions | [accumulated fee]
- Filename: `Transactions_[period]_[date].csv`

## PDF Export

- Portrait A4
- Header: Republic, City, Barangay, Office
- Title: Document Transactions Report
- Filter info: Period, Personnel
- Table: auto-paginated via autoTable
- Totals: Total Transactions + Accumulated Fee (PHP)
- Footer: Generated on date + Generated by user
- Filename: `Transactions_[period]_[date].pdf`
