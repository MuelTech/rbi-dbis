# Demographic PDF Report Design

## Overview

Generate PDF reports for residents filtered by demographic criteria for barangay programs (school supplies, senior assistance, PWD assistance, etc.).

## Filter Options

### Demographics
- Male
- Female
- Voter / Non-Voter
- Senior Citizen (age >= 60)
- PWD (Person with Disability)
- Solo Parent
- Family Head

### Student Types
- Day Care
- Kinder
- Elementary
- High School
- Senior High
- College
- ALS (Alternative Learning System)

### Age Range
- Custom age range (min - max)

### Status
- Active
- Deceased
- Moved Out

## Report Format

### Header
```
Republic of the Philippines
City of Manila
BARANGAY 418 ZONE 43 DISTRICT IV
Office of the Barangay Chairman

[REPORT TITLE - e.g., "List of Senior Citizens"]
```

### Table Columns

| # | Column | Width |
|---|--------|-------|
| 1 | No. | 5% |
| 2 | Last Name | 15% |
| 3 | First Name | 15% |
| 4 | Middle Name | 12% |
| 5 | Age | 6% |
| 6 | Sex | 6% |
| 7 | Address | 20% |
| 8 | Contact | 12% |
| 9 | Status | 7% |
| 10 | Signature | 7% |

### Sorting
Alphabetical by Last Name, then First Name

### Footer
```
Total Count: [number]
Generated on: [date]
Generated by: [current user]
```

## Implementation

### Library
`jspdf` + `jspdf-autotable`

### Files
1. `packages/desktop/package.json` - Add jspdf
2. `packages/server/src/controllers/reportController.ts` - Filter endpoint
3. `packages/server/src/routes/report.ts` - Route
4. `packages/desktop/src/services/report.ts` - Service
5. `packages/desktop/src/utils/pdfGenerator.ts` - PDF generation
6. `packages/desktop/src/pages/Dashboard.tsx` - Add PDF button
