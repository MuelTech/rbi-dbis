# PDF Report Refactor Design

## Overview

Refactor the PDF report to use portrait orientation and simplified columns.

## Changes

### Orientation
- Landscape → Portrait (A4)

### Columns

| Column | Width | Content |
|--------|-------|---------|
| No. | 10% | Row number |
| Name | 45% | Last Name, First Name Middle Name |
| Sex | 10% | Male/Female |
| Address | 25% | Full address |
| Signature | 10% | Blank space |

### Header
Same format, centered for portrait:
```
Republic of the Philippines
City of Manila
BARANGAY 418 ZONE 43 DISTRICT IV
Office of the Barangay Chairman

[REPORT TITLE]
```

### Footer
```
Total Count: [number]
Generated on: [date]
Generated by: [current user]
```
